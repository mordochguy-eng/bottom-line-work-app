# בשורה התחתונה — עבודה

גרסה מצומצמת של הדשבורד האישי [bottom-line](../bottom-line), מותאמת לניהול קבוצות וואטסאפ בהקשר העבודה, עם כפתור סנכרון קוד בין מחשבים.

---

## פיצ'רים

| פיצ'ר | תיאור |
|-------|-------|
| 🤖 **סיכומי AI יומיים** | Gemini מסכם כל קבוצה במעקב לתקציר, נושאים ומשימות |
| ✅ **משימות** | חילוץ אוטומטי מהסיכומים, עם סימון בוצע/שמור להמשך |
| 📨 **הודעות מתוזמנות** | טקסט, מדיה (תמונה/וידאו/אודיו/קובץ לפי URL), מיקום, סקר, או איש קשר — עם חיפוש נמען מתוך קבוצות/אנשי קשר + בדיקת מספר, ותזמון עם חזרה יומית/שבועית/חודשית. פועל רק כשהאפליקציה רצה בפועל — אם המחשב היה כבוי בזמן השליחה, ההודעה **לא** נשלחת באיחור (מסומנת "נכשל" אם עברה יותר משעה מהזמן שתוכנן), בדיוק כמו ב-bottom-line האישי |
| ☀️ **תדרוך בוקר** | הודעת וואטסאפ יומית עם משימות קרובות/באיחור |
| 🤖 **מענה אוטומטי מאושר** | מאזין (polling) לצ'אטים אישיים, מנסח טיוטת תשובה עם Gemini לאנשי קשר מאושרים או שאלות נפוצות — **שום דבר לא נשלח בלי אישור ידני** |
| 🎧 **האזנה חיה למשימות** | מאזין (polling) לכל הודעה נכנסת — בקבוצות ובצ'אטים אישיים — ובודק עם Gemini אם היא דורשת ממך פעולה. אם כן, מתווספת אוטומטית ללשונית משימות. תור ריק נבדק כל 4 שניות; כשיש כמה הודעות ביחד הן מתעבדות ברצף מהיר. כפתור **"סנכרן עכשיו"** מריק את התור מיידית, כולל כל מה שהצטבר בזמן שההאזנה הייתה כבויה (Green API שומר את התור לזמן מוגבל גם אז) |
| 🔢 **מיון בכל טבלה** | לחיצה על כותרת עמודה בכל טבלה באפליקציה (קבוצות, משימות, הודעות מתוזמנות) ממיינת לפיה |
| 🔄 **סנכרון גרסה** | כפתור בהגדרות שמושך את הקוד העדכני מהריפו הציבורי ומעדכן את המחשב הזה — בלי git, בלי חשבון מחובר |

## ארכיטקטורה

```
bottom-line for S-On/
├── backend/
│   ├── server.js        ← Express API, cron (סיכום יומי, תדרוך, הודעות מתוזמנות)
│   ├── database.js      ← קריאה/כתיבה לקבצי JSON תחת data/ (לא מסונכרן בין מחשבים)
│   ├── greenApi.js       ← Green API: צ'אטים, שליחה, ותור ההתראות (polling)
│   ├── gemini.js         ← סיכום AI + ניסוח טיוטת מענה אוטומטי + חילוץ משימות מהאזנה חיה
│   ├── messageListener.js ← לולאת polling אחת על תור ההתראות (מתייעלת כשמצטברות הודעות), מזינה גם את תור אישור התגובות וגם את חילוץ המשימות החי, וחושפת drainQueueNow() לכפתור "סנכרן עכשיו"
│   ├── scheduler.js      ← לוגיקת תזמון טהורה (isDue/isExpired/retry)
│   ├── sync.js           ← מוריד zip מהריפו הציבורי ומחליף את קבצי הקוד
│   └── data/             ← ⚠️ לא עולה לגיט — נתונים אישיים לכל מחשב בנפרד
├── frontend/
│   └── src/pages/         ← דף הבית, קבוצות, משימות, תור אישור, הודעות מתוזמנות, הגדרות
├── scripts/
│   ├── register-autostart-task.ps1 ← רושם Task Scheduler להפעלה אוטומטית (כמו bottom-line האישי)
│   └── start-and-notify.ps1        ← מריץ pm2 resurrect + התרעת Windows, מופעל ע"י ה-task
├── sync-config.json       ← {"repo": "owner/name", "branch": "main"} — עולה לגיט
├── ecosystem.config.cjs   ← הגדרות PM2 (כמו bottom-line האישי)
├── start-pm2.bat
└── Register-AutoStart.bat ← חד-פעמי: רושם את ההפעלה האוטומטית
```

**פורטים** (שונים מה-bottom-line האישי כדי לרוץ במקביל על אותו מחשב): backend `5101`, frontend `5174`.

## הרצה ראשונה

```bash
cd backend && npm install
cd ../frontend && npm install
```

הפעלה קבועה (מומלץ):
```bash
pm2 start ecosystem.config.cjs
pm2 save
```

או הרצה ידנית לבדיקה: `node backend/server.js` בחלון אחד, `npm run dev` בתוך `frontend/` בחלון שני.

לאחר מכן פתח את **הגדרות** באפליקציה והזן את פרטי Green API ו-Gemini API שלך.

## סנכרון בין מחשבים

כפתור **"סנכרן גרסה עכשיו"** בהגדרות מושך zip עדכני מהריפו הציבורי המוגדר ב-`sync-config.json`, מחליף את קבצי הקוד (לא נוגע ב-`backend/data/`), ומפעיל מחדש את השרתים (דרך PM2).

**שני הריפואים** (בדומה למחולל כרטיסי הטיסה):

| ריפו | מצב | תפקיד |
|---|---|---|
| [`bottom-line-work`](https://github.com/mordochguy-eng/bottom-line-work) | פרטי | ריפו העבודה השוטפת |
| [`bottom-line-work-app`](https://github.com/mordochguy-eng/bottom-line-work-app) | ציבורי | קבצי הפצה בלבד (בלי `data/`) — זה שהכפתור מושך ממנו |

**אחרי כל שינוי קוד** יש להריץ **`Publish.bat`** כדי לעדכן את הריפו הציבורי — אחרת כפתור הסנכרון ימשיך להגיש גרסה ישנה. הסקריפט לוקח את קבצי ה-git הנוכחיים (לא נוגע ב-`data/`) ודוחף אותם לריפו הציבורי.

**מחשב חדש (למשל מחשב העבודה) — הורדה ראשונית בלי git ובלי חשבון GitHub:**
1. גלוש אל https://github.com/mordochguy-eng/bottom-line-work-app → כפתור ירוק **Code** → **Download ZIP**
2. חלץ לתיקייה, למשל `C:\AI Software\bottom-line for S-On`
3. `npm install` בתוך `backend/` ובתוך `frontend/`
4. הרץ עם `start-pm2.bat` (או `node backend/server.js` + `npm run dev` בשני חלונות)
5. **חד-פעמי, כדי שהאפליקציה תעלה אוטומטית באתחול/כניסה/התעוררות משינה** (בדיוק כמו ה-bottom-line האישי): לחיצה כפולה על **`Register-AutoStart.bat`**. לא צריך הרשאת מנהל. רושם משימת Task Scheduler בשם `BottomLineWork-AutoStart` שמריצה `pm2 resurrect` ומציגה התרעת Windows עם התוצאה.

מכאן והלאה — כפתור **"סנכרן גרסה"** בהגדרות מספיק לכל עדכון, בלי לחזור על השלבים האלו.

**חלופה למחשב שלך, שבו כבר יש git מחובר:**
```bash
gh auth login
gh repo clone mordochguy-eng/bottom-line-work "C:\AI Software\bottom-line for S-On"
```
