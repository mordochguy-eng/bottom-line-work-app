# הודעות מתוזמנות בענן — Cloudflare Worker

פותר בעיה אחת בלבד: **הודעות מתוזמנות שיוצאות בזמן גם כשהמחשב כבוי.** שאר האפליקציה (סיכומים, משימות, האזנה חיה, תדרוך בוקר) ממשיכה לרוץ מקומית כרגיל — זה לא מעביר את כל הדשבורד לענן, רק את תור ההודעות המתוזמנות.

הכול קורה דרך אתר Cloudflare — **בלי שורת פקודה, בלי CLI, בלי npm.**

---

## למה זה בטוח

ל-Worker אין ממשק משתמש, אין בו את הסיכומים/המשימות/התכתובות שלך — רק תור הודעות מתוזמנות ופרטי Green API לצורך שליחתן. כל בקשה אליו חייבת לשאת טוקן סודי (`AUTH_TOKEN`) שאתה קובע בעצמך — בלי הטוקן הזה, אף אחד לא יכול לגעת בו, גם אם ימצא את הכתובת.

---

## הקמה (חד-פעמית, כ-10 דקות)

### 1. חשבון Cloudflare
גלוש אל https://dash.cloudflare.com/sign-up ותירשם (אימייל בלבד, בלי כרטיס אשראי).

### 2. יצירת ה-Worker
1. בתפריט הצד: **Workers & Pages** ← **Create** ← **Create Worker**
2. תן שם (למשל `bottom-line-scheduler`) ← **Deploy** (יוצר גרסת ברירת מחדל — נחליף אותה מיד)
3. **Edit code** (או "Quick Edit")
4. מחק את כל התוכן הקיים, והדבק במקומו את כל התוכן של הקובץ [`worker.js`](worker.js) מהתיקייה הזו
5. **Save and deploy** (או **Deploy** בפינה)
6. שמור את הכתובת שמופיעה למעלה — היא בפורמט `https://bottom-line-scheduler.<שם-המשתמש>.workers.dev`

### 3. חיבור מקום אחסון (KV)
1. באותו Worker: **Settings** ← **Variables and Secrets** ← גלול ל-**KV Namespace Bindings** ← **Add binding**
2. אם אין עדיין namespace: **Create new** — שם למשל `bottom-line-queue`
3. **Variable name:** בדיוק `QUEUE` (כך בקוד קורא לו) ← **Save**

### 4. הגדרת הטוקן הסודי
1. עדיין ב-**Variables and Secrets** ← **Add variable**
2. **Name:** בדיוק `AUTH_TOKEN`
3. **Value:** מחרוזת אקראית וארוכה משלך (למשל 30+ תווים אקראיים — אפשר להיעזר במחולל סיסמאות)
4. סמן **Encrypt** ← **Save**
5. **שמור את הערך הזה בצד** — הוא יוזן גם בהגדרות האפליקציה שלך, ולא ניתן לצפות בו שוב אחרי השמירה.

### 5. הפעלת ה-Cron Trigger (בדיקה כל דקה)
1. באותו Worker: **Settings** ← **Triggers** ← **Cron Triggers** ← **Add Cron Trigger**
2. הזן: `* * * * *` (כל דקה) ← **Add**

### 6. חיבור לאפליקציה
1. פתח את **⚙️ הגדרות** באפליקציה
2. תחת **☁️ הודעות מתוזמנות בענן**, הזן:
   - **כתובת ה-Worker** — הכתובת מ**שלב 2**
   - **טוקן אבטחה** — הערך מ**שלב 4**
3. לחץ **☁️ שמור וסנכרן פרטי Green API ל-Worker** — זה שולח את פרטי ה-Green API שלך (שכבר מוגדרים למעלה בעמוד) ל-Worker, כדי שיוכל לשלוח הודעות בעצמו
4. אמור להופיע תג **"מחובר ומוגדר"** ירוק

מכאן והלאה — הודעות מתוזמנות שתיצור בלשונית "הודעות מתוזמנות" נשמרות ונשלחות דרך ה-Worker, לא מהמחשב. אם המחשב כבוי בזמן שהודעה אמורה לצאת, היא עדיין תישלח בזמן (או בפער של עד דקה).

**אותה התנהגות כמו במקומי:** אם המחשב/האפליקציה היו כבויים יותר משעה מהזמן המתוכנן, ההודעה **לא** נשלחת באיחור — מסומנת "נכשל" במקום.

## אם תרצה לעדכן את הקוד בעתיד

פשוט חזור ל-**Edit code** באתר Cloudflare, הדבק את הגרסה המעודכנת של `worker.js`, ולחץ **Deploy**. אין קשר בין זה לבין כפתור "סנכרן גרסה" של האפליקציה המקומית — שני מנגנוני עדכון נפרדים.
